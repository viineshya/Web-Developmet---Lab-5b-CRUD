# Web Development Lab 5b – PHP CRUD Form

## Project Description
This project is developed as part of Lab 5b for the Web Development course. It demonstrates the implementation of server-side scripting using PHP and MySQL to perform CRUD (Create, Read, Update and Delete) operations.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP
- phpMyAdmin

## Database Information
- Database Name: Lab_5b
- Table Name: users


## Table Fields

| Field    | Data Type    |
|----------|--------------|
| matric   | VARCHAR(10)  |
| name     | VARCHAR(100) |
| password | VARCHAR(255) |
| role     | VARCHAR(10)  |


## System Features
1. User Registration
2. User Login and Authentication
3. Display User Records
4. Update User Information
5. Delete User Records
6. Session Management
7. Logout Functionality

## How to Run the Project
1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Create the Lab_5b database in phpMyAdmin.
4. Create the users table using the required SQL structure.
5. Place the project folder inside the htdocs directory.
6. Open your browser and access:

   http://localhost/lab_5b/login.php

## Repository Contents
This repository contains the PHP source code and CSS file for the Lab 5b CRUD application.
